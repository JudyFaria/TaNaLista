description: Use antes de commitar para revisar o git diff. Dispara quando eu pedir para revisar mudanças, checar o diff ou "revisar antes do commit".
---

Revise as mudanças atuais do repositório (git diff):

1. Liste os arquivos alterados e resuma em uma frase o que mudou em cada um.
2. Aponte riscos: erros de lógica, código sem uso, dependência nova sem motivo, segredo ou chave exposta.
3. Diga se algo foge do que foi pedido na tarefa.
4. Termine com uma lista curta: o que aceitar e o que questionar.

Seja direto e não altere nenhum arquivo.
